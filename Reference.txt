							  Orb[it]-VM Reference Manual

| About:
| 	Orb[it]-VM (also called O-VM) is a small, lightweight virtual machine that operates on a custom bytecode format.
|	O-VM is a memory/register based VM with addresses ranging from "01" -> "zz".
|	The format (a 4 block structure) is as follows: INSTRUCTION ARG0, ARG1, ARG2.

|	Each bytecode is only two characters long (ie. "00") with a few exexceptions.
|	Anything surrounded by '[]' denotes that it is either a float value, an integer value over 99, a string, or a special register location.
|	Anything start with either ["@", "$", "%"] represent the location in a given memory pool

|	The 4 Memory Locations:
|	 - The Global Memory Pool (denotated by @<register address>) [ie. @01]
|	 - The Local Memory Pool (denotated by $<register address>)  [ie. $02]
|	 - The Buffer Memory Pool (denotated by %<register address>) [ie. $03]
|	 - Special Register Locations (denotated by [<special register address>])

| NOTES:
|	Strings do NOT contain quotation marks unless contained within the string itself 
| 	Special register values take priority over string values:
|	 - [sra] will only be the string "sra" IF AND ONLY IF the special register [sra] is empty (sra == "")

| INSTRUCTIONS: (NAME: OPCODE: [Arguments])

| NOP:    00 [None, None, None]
| READ:   01 [Store Location, None, None]
| WRITE:  02 [Data Location/String Literal, None, None]
| STORE:  03 [Store Location, Data, None]
| DEL:    04 [Location, None, None]
| COPY:   0A [Copy Location, Data]
| UPD:    0G [Location, Data, None]
| MALLOC: 0H [Memory Pool Type, Amount, None]
| FREE:   0I [Memory Pool Type]

| ADD:    05 [Location/Number, Location/Number, Store Location [sra by default]]
| SUB:    06 [Location/Number, Location/Number, Store Location [sra by default]]
| MUL:    07 [Location/Number, Location/Number, Store Location [sra by default]]
| DIV:    08 [Location/Number, Location/Number, Store Location [sra by default]]
| EXP:    09 [Location/Number, Location/Number, Store Location [sra by default]]
| INC:    0E [Location: Number, None, None]
| DEC:    0F [Location: Number, None, None]

| JMP:    0B [Label location, None, None]
| JNE:    0C [Label Location, Location/Number, None]
| CMP:    0D [Location, Location, None]

| LBL:    0J [None, None, None]
